# Credits

Raven is better because of the people below. Anyone whose work has improved Raven is listed here, whatever their role and whether or not they write code.

## Contributors

- **Sepehr Rajabi** ([@SepehrRajabi](https://github.com/SepehrRajabi)): Raven's first outside contributor. Brought Raven to macOS, made display name changes appear immediately in calls, made server addresses default to a secure connection, and moved the desktop type check to TypeScript 7 ([#1](https://github.com/raven-collective/raven-prototype/pull/1), 0.1.11). Added link previews in chat ([#4](https://github.com/raven-collective/raven-prototype/pull/4), 0.1.11). Made closing the window from full screen work on macOS and opened search with Command K there ([#3](https://github.com/raven-collective/raven-prototype/pull/3)). Added polls to chat, with feedback from the asker on each answer, and made each past server appear once on the sign-in screen ([#9](https://github.com/raven-collective/raven-prototype/pull/9)). Updated the desktop, admin and release-verifier dependencies ([#10](https://github.com/raven-collective/raven-prototype/pull/10)). Added search to the Settings sidebar ([#20](https://github.com/raven-collective/raven-prototype/pull/20)). Alpha tester.
- **Ali Esmaili Seraji** ([@hu13er](https://github.com/hu13er)): proposed port sharing, which shipped in 0.1.9 and grew into the Workshop. Has guided Raven's architecture and software design, particularly for its most complex features. Alpha tester.
- **Ali Mirlou** ([@alimirlou](https://github.com/alimirlou)): feedback on the sidebar redesign that shaped how it presents places, people and live calls (0.1.12). Alpha tester.
