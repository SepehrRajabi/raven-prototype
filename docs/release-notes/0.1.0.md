# Raven 0.1.0 closed alpha

This is Raven's first friends-only Windows and Linux release.

## Included

- Private Raven accounts, Trees, Nests, presence, invitations, and session management.
- Live audio, camera, and screen sharing through the production Raven RTC service.
- Native microphone, speaker, camera, and screen-capture controls with per-source audio mixing.
- Voice overlay, configurable media hotkeys, network activity, and fullscreen media controls.
- User and Tree profile images stored in Raven's private object storage.
- Signed updates: Raven tells you when a new version is out and installs it when you ask.

## Closed-alpha notes

- Windows packages are protected by Raven's updater signature but are not yet Authenticode-signed, so Windows may show an unknown-publisher warning.
- Linux is distributed as an x86-64 AppImage. Make the file executable before launching it.
- Raven is an early alpha. Please report sign-in, device, call, update, or startup problems directly to the Raven maintainer.
